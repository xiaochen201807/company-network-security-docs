# 安全门禁、例外与度量

## 门禁流水线

~~~text
提交 → 评审 → 凭据扫描 → SAST → SCA → 测试
→ Build → Artifact/Image Scan → Gate → Release → Production
~~~

## 阻断条件

高可信 凭据、新增 Critical、已确认严重 SAST、已被利用高风险依赖、制品不可追溯、关键测试失败。

## 例外记录发现项/Control、Business Reason、风险、补偿控制、负责人、Reviewer、Approver、Expiry、Fix Plan。禁止永久例外。

## 误报 / 复测

误报必须有技术证据；修复后通过相应扫描或人工验证复测再关闭。

## 度量覆盖率、Critical/High、Overdue、MTTR、Gate Block、Bypass、例外、False Positive、SBOM/Provenance 覆盖率。

## 控制项

SEC-SUP-*、SEC-VUL-*、SEC-GOV-002。
