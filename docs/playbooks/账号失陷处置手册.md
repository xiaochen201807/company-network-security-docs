# 账号失陷处置手册

| Metadata | Value |
|---|---|
| Document ID | SEC-PLB-IR-001 |
| Type | Playbook |
| 负责人 | Security/SOC |

## 触发条件

异常登录、令牌泄露、钓鱼凭据提交、MFA 异常或其他账号被控迹象。

## 立即处置

1. 确认账号类型与权限。
2. 禁用账号或强制密码重置。
3. 撤销 Session/令牌。
4. 检查 MFA 变化。
5. 搜索异常登录和管理操作。
6. 检查新增令牌/OAuth App/API 密钥。
7. 检查横向使用。
8. 高权限账号立即升级 Incident。

## 邮件账号补充处置

检查 Inbox Rule、External Forwarding、Sent Mail、OAuth Consent。

## 云平台 / 管理员账号补充处置

检查 IAM、Role、Security Group、New Credential、Resource Creation。

## 恢复

重新启用前确认设备可信、凭据已轮换、恶意持久化已清理。

## 证据

Identity Log、MFA、Session、令牌、Endpoint、Email/Cloud Audit。
