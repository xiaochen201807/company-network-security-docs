# 凭据泄露处置手册

| Metadata | Value |
|---|---|
| Document ID | SEC-PLB-IR-002 |
| Type | Playbook |
| 负责人 | Security/DevOps |

## 触发条件

Git、CI Log、Artifact、Chat、Ticket、Email 或扫描器发现 Password、令牌、私钥、AccessKey。

## 立即处置

1. 不等待删除代码，立即判断 凭据 是否真实。
2. 吊销/禁用旧 凭据。
3. 创建新 凭据。
4. 更新所有合法使用方。
5. 查询旧 凭据 的历史使用日志。
6. 检查是否存在未授权访问。
7. 清理 Git/Artifact/Log 等传播位置。
8. 如已被利用，升级安全事件。

## 特殊场景

### 云访问密钥（AccessKey）
禁用 Key，检查 IAM/Cloud Audit、资源创建和数据访问。

### 私钥 / 证书
吊销/替换证书或可信关系，检查使用范围。

### CI/CD 凭据
检查最近 Pipeline、Artifact 和 Production Deploy。

## 关闭条件

凭据 已轮换、旧凭据不可用、使用范围明确、无未处理异常访问、根因有整改。
