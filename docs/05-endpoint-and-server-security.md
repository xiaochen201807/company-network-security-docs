# 05 - 终端与服务器安全

> 本文档用于规范 Windows、Linux、办公终端、生产服务器、虚拟机、中间件宿主机的基线、补丁、EDR、日志、远程管理和恶意软件防护。

## 1. 目标

- 减少默认配置和不必要服务带来的攻击面。
- 确保高风险补丁按 SLA 处理。
- 终端与服务器具备恶意行为检测能力。
- 管理操作实名、受控、可审计。
- 关键主机配置能够持续检查并发现偏差。

## 2. 适用范围

- Windows 办公终端与服务器
- Linux 服务器
- 虚拟机
- 云主机
- 堡垒机/运维终端
- Jenkins Agent
- 数据库/中间件宿主机
- Docker/Kubernetes Node

## 3. 控制级别

- **MUST**：生产和关键终端的强制控制。
- **SHOULD**：应尽量实施。
- **MAY**：增强控制。

## 4. 通用操作系统基线

### 4.1 最小化安装
删除或禁用无业务用途的软件包、服务、端口和默认组件。

### 4.2 默认账号与口令
必须修改默认口令，禁用不需要的默认账号、Guest、Demo、Test 等账号。

### 4.3 时间同步
所有主机 MUST 使用可信 NTP/时间服务，以保证日志和事件时间线可靠。

### 4.4 主机名与资产
生产主机应有规范主机名、Asset ID、Owner、环境标签并纳入资产台账。

### 4.5 日志
操作系统认证、权限提升、系统服务、关键配置变化和安全日志应集中采集。

## 5. Linux 安全

### 5.1 SSH
- 禁止公网无保护直接暴露。
- 禁止弱口令。
- 优先密钥/统一认证。
- 限制 root 直接登录。
- 限制登录来源。
- 禁止已知不安全算法。
- 记录登录失败和 sudo。

### 5.2 sudo
生产管理员优先普通账号登录后 sudo。sudoers 权限最小化，避免长期 NOPASSWD ALL。

### 5.3 文件权限
重点检查：

- /etc/passwd、/etc/shadow
- SSH Key
- 应用配置
- 私钥/证书
- 启动脚本
- 日志目录

敏感文件不得对无关用户可读写。

### 5.4 服务与端口
定期核对 ss/netstat 与资产台账。未知监听端口必须调查。

### 5.5 内核与系统参数
按公司基线评估：

- IP 转发
- ICMP
- core dump
- ptrace
- 文件描述符
- ASLR
- 审计
- 防火墙

不能机械套用基线导致业务异常。

### 5.6 定时任务
检查 cron/systemd timer，防止未知脚本、过宽权限和明文 Secret。

## 6. Windows 安全

### 6.1 本地管理员
普通办公用户原则上不长期持有本地管理员权限。

### 6.2 RDP
- 不公网暴露。
- 通过 VPN/堡垒机。
- 开启强认证。
- 管理员账号受控。
- 登录日志集中。

### 6.3 Windows Update
安全更新按风险和变更窗口管理。

### 6.4 Defender/EDR
关键终端和服务器必须纳入公司批准的防恶意软件/EDR 平台。

### 6.5 PowerShell
应保留必要日志；高风险脚本执行纳入检测；生产环境避免无控制执行互联网下载脚本。

### 6.6 SMB
关闭不需要的旧协议，限制文件共享范围，禁止无认证共享。

## 7. 办公终端

办公终端 SHOULD：

- EDR/杀毒纳管。
- 自动安全更新。
- 磁盘加密。
- 屏幕锁定。
- 浏览器保持受支持版本。
- 禁止安装未知来源软件。
- USB/外设按风险管理。
- 企业数据与个人数据适当隔离。

## 8. 磁盘加密

笔记本和存储敏感数据的终端 SHOULD 启用全盘加密。恢复密钥应受控保存，不能只由单个员工个人掌握。

## 9. EDR/防恶意软件

### 9.1 纳管
生产服务器和员工终端按风险纳管。

### 9.2 防护
策略包括：

- 恶意文件检测
- 可疑进程
- 持久化
- 横向移动
- 勒索行为
- WebShell/脚本
- 异常网络连接

### 9.3 关闭保护
未经授权关闭 EDR/杀毒视为安全告警。

## 10. 应用白名单与软件安装

关键管理终端和高风险环境 MAY 使用应用控制/白名单。普通用户不应随意安装破解软件、来源不明驱动、远控软件和未知浏览器插件。

## 11. 远程控制工具

TeamViewer、AnyDesk、ToDesk 等远控工具需要公司策略明确。未经批准的远控软件应检测和清理。

## 12. 补丁管理

统一流程：

~~~text
安全公告 → 影响判断 → 资产确认 → 风险定级
→ 测试 → 变更审批 → 部署 → 功能验证 → 安全验证 → 记录
~~~

## 13. 补丁优先级

优先处理：

- 已被真实利用
- 公网可达
- 远程代码执行
- 权限提升
- 核心服务器
- 域控/IAM
- VPN
- Git/Jenkins
- 大规模受影响资产

## 14. 紧急补丁

紧急漏洞处理时应同时考虑稳定性：

- 是否可先隔离或 ACL
- 是否有 WAF/IPS 缓解
- 是否可切流
- 是否有回退方案
- 是否需要维护窗口

安全紧急不等于跳过变更管理。

## 15. EOL 操作系统

已停止安全更新的 OS：

- 禁止新增部署。
- 建立升级/替换计划。
- 强化网络隔离。
- 无法整改时进入风险例外。

## 16. Nginx

重点：

- 使用受支持版本。
- 非必要不暴露版本信息。
- TLS 配置安全。
- 管理/状态接口限制来源。
- 配置文件权限。
- 访问/错误日志接入。
- 上传大小与超时合理。
- 反向代理 Header 正确。

## 17. Tomcat

重点：

- 删除/限制 Manager、Host Manager 等管理应用。
- 修改默认账号。
- 管理接口不公网暴露。
- 使用受支持版本。
- server.xml/context.xml 权限。
- 应用运行账号非 root。
- 日志集中。

## 18. JDK/JVM

- JDK 使用受支持版本。
- 生产禁用无必要调试/JMX 公网暴露。
- JMX 如启用必须认证和限制来源。
- Heap Dump/Core Dump 作为敏感数据保护。
- GC 日志和 JVM 指标接入监控。
- JVM 启动参数受版本控制。

## 19. Redis

- 不公网暴露。
- 开启认证/ACL。
- 限制 bind/network。
- 禁止危险默认配置。
- 数据目录权限受控。
- 备份与持久化策略明确。
- 高风险命令按业务限制。

## 20. MySQL/PostgreSQL

- 不公网暴露。
- 应用账号非 root/superuser。
- 管理员账号实名或受 PAM 管理。
- 远程来源限制。
- 审计高风险操作。
- 备份恢复验证。
- 配置文件和凭据权限受控。

## 21. Elasticsearch

- 不无认证公网暴露。
- 开启认证授权。
- 管理 API 限制来源。
- TLS 按部署需要启用。
- 索引敏感数据访问最小化。
- 快照备份受控。

## 22. MQ

RabbitMQ/Kafka 等：

- 管理控制台不公网暴露。
- 默认账号处理。
- 生产认证授权。
- Topic/Queue 权限最小化。
- TLS 按敏感性启用。
- 管理操作日志可追踪。

## 23. Docker Host

- Docker daemon 不公网无认证暴露。
- /var/run/docker.sock 严格限制。
- 宿主机与容器补丁同步治理。
- 清理未知镜像和容器。
- Registry 凭据受控。

## 24. 主机防火墙

Linux/Windows 主机防火墙 SHOULD 用于补充网络边界，尤其是：

- 管理端口
- 数据库
- 中间件
- 集群控制面

## 25. 配置漂移

关键主机 SHOULD 通过 Ansible、配置管理或基线扫描持续发现：

- 新端口
- 新账号
- sudo 变化
- 安全服务被关闭
- 配置偏离

## 26. 主机日志

至少考虑：

### Linux
- auth/authpriv
- sudo
- SSH
- systemd/service
- auditd（如启用）
- kernel

### Windows
- Security
- System
- PowerShell
- Defender/EDR
- RDP

## 27. 检测场景

- 暴力破解
- 新增管理员
- 异常 sudo
- 新服务/计划任务
- EDR 被关闭
- 可疑 PowerShell
- WebShell
- 异常外连
- 加密/勒索行为
- 批量文件修改

## 28. 备份与恢复

主机配置和关键中间件配置应备份。配置备份需保护 Secret，恢复方案定期验证。

## 29. 指标

- EDR 覆盖率
- 高风险补丁超期率
- EOL 主机数量
- 公网 SSH/RDP 数量
- 基线不合规数量
- 默认/弱口令数量
- 安全日志接入率

### P0
