# 30 - 安全意识、安全倡导者与安全人才体系

> 安全能力不能只依赖安全团队。本章建立全员安全意识、角色化培训、安全倡导者 和关键岗位能力模型。

## 1. 目标

- 全员掌握基础安全行为。
- 高风险岗位接受针对性培训。
- 研发和运维具备必要安全能力。
- 安全倡导者 将安全融入团队日常。
- 安全事件和演练反向驱动培训。
- 关键安全能力不依赖单个人。

## 2. 培训分层

### 一级 - 全员
- Phishing。
- Password/MFA。
- Data Handling。
- Device。
- Incident Reporting。
- AI 使用边界。

### 二级 - 角色定向
研发、运维、管理员、财务、HR、采购等专项培训。

### 三级 - 专项岗位
Security、SRE、Architect、Champion 深度能力。

## 3. 新员工

入职安全培训：

- 账号安全。
- MFA。
- 设备。
- 数据。
- 邮件。
- 公司安全报告渠道。
- 可接受使用政策。

应在合理期限内完成并留证据。

## 4. 年度培训

年度复训根据真实事件调整内容，而不是每年播放完全相同视频。

## 5. 研发培训

重点：

- Authentication/Authorization。
- SQLi。
- SSRF。
- Upload。
- 凭据。
- Dependency。
- 威胁模型ing。
- Secure Logging。
- Spring Security。

培训最好结合公司真实代码案例。

## 6. DevOps/SRE 培训

重点：

- IAM。
- 凭据。
- Jenkins。
- Kubernetes。
- Cloud。
- Logging。
- IR。
- Backup/DR。
- Production Change。

## 7. 管理员培训管理员：

- PAM/JIT。
- MFA。
- Privileged Session。
- Break-glass。
- Incident。
- 证据。

## 8. 财务 / 人力 / 采购

重点：

- BEC。
- Impersonation。
- Invoice Fraud。
- Sensitive Data。
- Third-party 风险。
- Verification Channel。

## 9. 管理层

管理层培训：

- 风险接受责任。
- Incident 决策。
- Business Continuity。
- Regulatory/Contract 风险。
- Security Investment。

## 10. 钓鱼演练

指标：

- Click Rate。
- Credential Submission（仅安全演练设计允许时）。
- 报告 Rate。
- Repeat Failure。
- Department Trend。

目标是提升识别和报告能力，不以羞辱或惩罚作为主要方式。

## 11. 即时培训

发生以下情况后提供针对性培训：

- 凭据泄露。
- 重复越权漏洞。
- 钓鱼点击。
- 错误数据外发。
- 不安全生产变更。

## 12. 安全倡导者

每个主要研发/平台团队可指定 Champion。

职责：

- 协助 威胁模型。
- 推动安全修复。
- 分享安全知识。
- 收集团队反馈。
- 参与 Security Community。

Champion 不替代 Security Team，也不承担所有风险责任。

## 13. 安全倡导者选拔

优先选择：

- 对安全感兴趣。
- 熟悉业务。
- 能影响团队工程实践。
- 有时间承担职责。

不建议仅按行政指派而不给时间。

## 14. 安全倡导者赋能

提供：

- 培训路径。
- Office Hour。
- 威胁模型 模板。
- Secure Coding Guide。
- 看板。
- 专项 Workshop。

## 15. 安全社区

定期：

- 分享漏洞案例。
- 新 CVE。
- Secure Coding。
- Cloud。
- AI。
- Incident Lessons Learned。

## 17. 关键人员风险识别：

- 只有一个人会处理 Jenkins。
- 只有一个人知道证书续期。
- 只有一个 IR 负责人。
- 只有一个数据库管理员。

建立 Backup 负责人和知识转移。

## 18. 演练

培训不只靠课程：

- Tabletop。
- 紫队。
- Restore Exercise。
- Phishing Simulation。
- Secure Coding Workshop。

## 19. 知识库

沉淀：

- FAQ。
- Runbook。
- Secure Example。
- Incident Lesson。
- 工具 Guide。
- Common Fix。

## 20. 度量

- 全员培训完成率。
- Role-based 覆盖率。
- Champion 覆盖率。
- Phishing 报告 Rate。
- 重复安全问题下降趋势。
- 演练完成率。
- 关键岗位 Backup 覆盖率。
