# 01 - 安全治理与制度

> 本文档规定公司安全治理、制度生命周期、风险管理、例外审批、人员责任、第三方风险和管理层监督的基本要求。

## 1. 目标

把安全从零散技术动作变成长期机制，做到有制度、有责任人、有审批、有证据、有检查、有整改、有复审。

## 2. 适用范围

适用于正式员工、外包、实习人员、供应商以及业务、研发、运维、SRE、安全、审计和管理人员。

## 3. 基本原则

### 3.1 管理层负责风险决策
安全团队发现风险并提出建议；重大剩余风险应由具备相应权限的业务或管理负责人接受。

### 3.2 制度必须可执行
制度应明确谁执行、执行什么、多久一次、留什么证据、不符合如何处理，避免只写“加强管理”。

### 3.3 职责分离
高风险操作尽量满足“申请人 ≠ 审批人”“开发人 ≠ 生产发布审批人”“漏洞修复人 ≠ 高风险例外最终审批人”。

## 4. 制度体系

至少维护：

1. 信息安全总则
2. 资产管理
3. 网络安全
4. 账号与权限
5. 密码与密钥
6. 终端与服务器
7. 安全开发
8. 软件供应链
9. 漏洞管理
10. 数据安全
11. 日志与安全运营
12. 事件响应
13. 备份与容灾
14. 变更与发布
15. 第三方安全
16. 安全例外

## 5. 制度文档要求

| 字段 | 要求 |
|---|---|
| Owner | 明确 |
| 版本 | 必须 |
| 生效日期 | 必须 |
| 适用范围 | 明确 |
| MUST 控制 | 可验证 |
| 例外方式 | 明确 |
| 审批人 | 明确 |
| 复审周期 | 明确 |
| 变更记录 | 保留 |

## 6. 制度生命周期

~~~text
起草 → 安全评审 → 业务/技术评审 → 审批 → 发布
→ 培训/宣导 → 执行 → 检查 → 定期复审 → 修订/废止
~~~

**SHOULD：正式制度至少每年复审一次。**

重大安全事件、架构重大变化、组织调整、新合同/监管要求或重大审计发现时应提前复审。

## 7. 风险管理

风险台账至少记录：

- 风险编号
- 资产
- 风险描述
- 威胁与脆弱性
- 影响与可能性
- 当前控制
- 初始风险和剩余风险
- 风险 Owner
- 整改计划
- 截止日期
- 状态

状态建议：New、Assessing、Mitigating、Monitoring、Accepted、Closed。

## 8. 风险处理

- **Mitigate**：增加控制降低风险。
- **Avoid**：停止高风险活动。
- **Transfer**：通过合同、保险或第三方转移部分风险。
- **Accept**：明确理解后接受剩余风险。

接受风险不等于“不处理、不记录”。

## 9. 安全例外

以下情况应走例外：

- 无法满足 MUST
- 无法按 SLA 修复高风险漏洞
- 临时开放高风险网络权限
- 临时使用不符合基线的软件
- 紧急绕过安全 Gate

例外必须包含原因、影响、补偿控制、Owner、审批人、生效时间、到期时间和正式整改计划。

**MUST：例外到期重新评估，禁止永久自动续期。**

## 10. 人员生命周期

### 入职
最小权限创建账号、确认制度、完成基础安全培训。

### 转岗
重新评估 Git、Jenkins、VPN、生产权限、数据访问。

### 离职
及时禁用账号、VPN、Token、SSH Key，回收设备并转移系统 Owner。

## 11. 安全培训

### 全员
钓鱼、密码、MFA、数据保护、异常报告。

### 开发
安全编码、OWASP、Secret、依赖漏洞。

### 运维
最小权限、基线、日志、变更、应急。

### 管理员
特权账号、审计、紧急权限。

## 12. 第三方与供应商

重要第三方准入应评估：

- 数据访问范围
- 网络访问范围
- 是否接触生产
- 是否持有公司凭据
- 安全事件通知能力
- 软件交付和更新方式
- 合作终止后的退出机制

第三方账号必须一人一号、有有效期、最小权限、可审计，到期回收。

## 13. 安全变更治理

防火墙、VPN、IAM、WAF、认证、加密、Jenkins、Git、数据库权限和安全 Gate 等高风险变更应有申请、审批、实施、验证和回退。

紧急变更可以简化前置流程，但必须有事后复审和临时权限回收。

## 14. 紧急权限

紧急生产权限必须：

- 有明确原因
- 有时间限制
- 有审批或事后复核
- 有完整日志
- 使用后回收

SHOULD 逐步采用 PAM/JIT 类方式。

## 15. 管理层安全报告

月度或季度至少关注：

- 重大风险
- Critical/High 漏洞
- 超期问题
- 安全事件
- 公网攻击面
- 重大例外
- 恢复演练
- 指标趋势

## 16. 审计证据

制度版本、审批、风险台账、例外、培训、权限复核、第三方评估、管理层报告和整改证据。

## 17. 指标

- 制度复审率
- 高风险例外数
- 过期例外数
- 风险按期关闭率
- 培训完成率
- 第三方账号超期数
- 离职权限回收及时率

## 18. 落地路线

### P0
制度清单、安全 Owner、风险台账、安全例外、离职回收、重大风险升级。

### P1
第三方准入、季度权限复审、管理 Dashboard、培训体系、安全变更分级。

### P2
GRC 平台、自动证据采集、风险量化、控制有效性自动验证。

- [ ] 第三方账号有有效期
- [ ] 离职权限及时回收
- [ ] 培训有记录
